# Research Analysis adapter

Read these repository files for the active role only:

- Worker: `Book Orchestrator Agent/research-analysis-node/Research Analysis Agent/SKILL.md`
- Evaluator: `Book Orchestrator Agent/research-analysis-node/Evaluate/SKILL.md`
- Diagnose: `Book Orchestrator Agent/research-analysis-node/Diagnose/SKILL.md`
- Node contract: `Book Orchestrator Agent/research-analysis-node/instruction.md`

The exact approved Broad Research Doc is the sole research source. Do not run fresh web searches.
Replace Gumloop and Slack with connected Google Drive tools. Publish the seven-section synthesis as
a new native Doc in the Research Analysis folder, preserving the Framing Check, tensions,
disconfirming evidence, and falsifier requirements.

Evaluate with the research_analysis rubric. Failed evaluation or human comments route to Diagnose,
which creates a new immutable version followed by mandatory re-evaluation. Maximum three Diagnose
attempts per review cycle. On a passing result, the controller asks the reviewer to inspect both the
synthesis and Framing Check; a proposed reframe is never adopted automatically.

Return metadata only. The controller owns Sheets, checkpoints, and approval.
